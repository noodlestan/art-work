# @art-board/cli

**Purpose:** Coordinate agent sessions around a whiteboard.

**Description:** A POC cli that monitors whiteboard participant sessions and dispatches "next turn" prompts.

## Installation

```bash
npm install -g @art-board/cli
```

## Usage

```bash
art-board-cli --help
```
